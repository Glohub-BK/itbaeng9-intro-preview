# ITbaeng9 mobile intro preview

Eight-second HTML motion design: a silver 3D phone, flowing violet/pink/cyan gradient, Korean ITbaeng9 channel identity, and simulated subscribe/like actions. Open the GitHub Pages site on mobile or desktop. No sound; no real account action is performed by the animation.

The mobile and landscape compositions share a deterministic paused GSAP timeline. The preview page owns playback, replay, scrubbing, and format switching. GSAP and Pretendard assets are included locally. See the bundled asset license headers and the Pretendard license file.
