# 후속 비교의 새 조건

이번 사용자 수정은 기존 스킬을 모두 제외한 GPT 6.1 Sol의 직접 코드 제작입니다. 앞서 만든 HyperFrames 시연과 이번 새 영상은 서로 다른 제작입니다.

정식 비교는 GPT·Claude·Gemini 모두 동일하게 스킬·템플릿·레지스트리·모션 프레임워크 없이 vanilla Canvas/JavaScript만 허용합니다. 같은 37.5초·1920×1080·60fps·128 BPM·80박·폰트·문구·프로젝트 소재를 제공합니다. 동일한 이번 오리지널 음악을 사용해 시각 결과와 박자 싱크를 비교합니다.

첫 실행과 같은 수정 요청 1회를 분리하며 모델 정확 ID·추론 설정·실행 시간·수정·실패·비용을 기록합니다. 구현 도구와 실행 환경 차이는 공개합니다. 이번 GPT 영상은 연출 수정을 거친 실제 작품이며 정식 첫 실행 비교 점수는 아직 없습니다. 다른 모델 결과도 미실행입니다.

미나의 롱폼 나레이션은 실제 결과와 제작 기록 확보 후 작성·합성합니다. 인물 출연 없이 설명합니다.
